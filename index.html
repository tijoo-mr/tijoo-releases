Tijoo

Le carnet de crédits des commerçants : clients, dettes, remboursements, rappels.

Télécharger pour Android · تحميل

Gratuit · Android 7 ou plus récent · version 1.0.2

Installation

  1. Appuyez sur « Télécharger » puis ouvrez le fichier Tijoo.apk.
  2. Si Android le demande, autorisez l'installation depuis cette source (Chrome ou Fichiers).
  3. Appuyez sur « Installer », puis ouvrez Tijoo.
  4. Créez votre compte, ou saisissez le code d'activation de votre boutique.

طريقة التثبيت

  1. اضغط على «تحميل» ثم افتح الملف Tijoo.apk.
  2. إذا طلب أندرويد ذلك، اسمح بالتثبيت من هذا المصدر (Chrome أو الملفات).
  3. اضغط على «تثبيت» ثم افتح تيجو.
  4. أنشئ حسابك، أو أدخل رمز تفعيل متجرك.
